# MyFolder v1.1.1 发布说明

发布日期：2026-08-13

MyFolder v1.1.1 以“多设备文件快捷传输”为核心，将原有文件上传能力扩展为包含设备管理、自动传输路由、共享存储以及完整账号认证体系的平台版本。

## 主要变化

### 设备体系

- 设备注册、身份维护和周期心跳
- 在线 / 离线状态与最近在线时间
- 设备名称、类型、操作系统、IP 和客户端版本信息
- Web 端设备列表、详情、重命名和移除

### 设备间文件发送

发送任务统一记录源设备、目标设备、文件清单、目标位置、大小和 SHA-256。系统按顺序尝试：

```text
LAN 直传 → P2P 直传 → Server Relay
```

- LAN 通道用于同一局域网设备之间的高速直传
- P2P 通道包含 NAT / STUN 探测和连接协商
- Relay 通道负责无法直连时的服务器中转
- 支持断点续传、分片上传、Range 下载、失败重试和任务恢复
- 使用清单和 SHA-256 验证文件完整性
- 使用 WebSocket 推送任务和进度状态

### Windows 桌面集成

- 右键菜单发送入口
- 单实例启动与外部命令转发
- 本地任务状态持久化
- 目标设备选择、传输进度与接收通知
- `myfolder://oauth/callback` OAuth 协议回调

### 账号认证与 OAuth

- 账号或邮箱密码登录
- 邮箱验证码注册
- 邮箱找回与重置密码
- Access Token + Refresh Token
- 会话刷新、退出与撤销
- Nyauth、Google、GitHub OAuth 登录
- OAuth `state`、PKCE 与 OIDC `nonce`
- 一次性 OAuth 登录交换凭据
- 第三方账号绑定与解除绑定
- 绑定前的邮箱验证码二次认证与敏感操作短时凭据
- 防止解除账号的最后一种登录方式

### 群组和共享存储

- 群组创建、重命名和删除
- 成员邀请、移除和角色调整
- 群组角色 `READ`、`WRITE`、`OWNER`
- 文件夹 ACL `NONE`、`READ`、`WRITE`、`MANAGE`
- 私有空间与群组空间切换
- 文件 / 目录管理、分片上传、下载、批量操作和回收站
- 存储配额与配额预留
