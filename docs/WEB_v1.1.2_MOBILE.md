# Server / Web v1.1.2 · 2026-10-25

## Web 更新

- 手机使用可关闭的导航抽屉，支持焦点循环、Escape 和背景滚动锁定；桌面继续使用侧栏。
- 文件列表在手机上显示为卡片，长文件名换行，下载、重命名、打开按钮附文字；批量操作和移动/上传弹窗适配窄屏。
- 群组成员、邀请表单、设备、传输、历史与设置页适配窄屏；历史记录保留流向、类型、大小、时间和结果。
- 修复中等宽度下长记录撑宽页面的问题；输入字号避免手机聚焦自动放大；适配安全区域和横屏。
- UI 使用统一的 `CLIENT_VERSION=1.1.2`；服务器增加桌面更新清单 API，设置页展示已发布安装包状态。

- 不修改账号、数据库、文件存储、生产环境变量和官网；回滚可从备份恢复 index 与对应资源。
